# Build Day starter: an avatar Muse chooses for itself

Spatial web (IWSDK 1.1 / WebXR) starter for the OpenRouter x Meta Build Day.
Muse designs its own reactive, ambient avatar; a second model reviews it; the
page renders it in passthrough on Quest 3 and Meta's VR glasses.

- **RUN-SHEET.md**: run it, open it on the Quest, set the key, restyle it.
- **PLAN.md**: the 60-minute plan, the duet, extension ideas, what Muse is good at.
- **AGENTS.md / CLAUDE.md**: IWSDK's own guidance for coding agents (from the
  official template); point Claude Code or Codex at the folder and they'll use it.
